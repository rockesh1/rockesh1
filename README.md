## 📁 Projects

### 🐟 Illegal Fishing Detection using Anomalous AIS Signals — *Published Research*
*Self-Supervised Transformers · Deep Learning · Python*

Developed a self-supervised transformer model to detect illegal fishing by identifying anomalous AIS signals across 25–50GB of real-world maritime AIS data, without requiring labelled data. Achieved **92.8% anomaly-detection accuracy**, outperforming baseline methods including SVM, Random Forest, LSTM, and Autoencoders. Designed masked-trajectory-prediction and sequence-continuation pretraining tasks with a custom loss function to flag AIS suppression; published as a peer-reviewed research paper.

### 🔥 Fire & Smoke Detection using Improved YOLOv8
*YOLOv8 · CBAM · Python*

Developed a real-time fire and smoke detection system by fine-tuning YOLOv8 on a custom dataset. Enhanced detection accuracy using advanced data augmentation, attention modules (CBAM), and optimized anchor boxes.
